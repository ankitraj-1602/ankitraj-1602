## 🚀 Featured Project

### [TaskFlow](https://github.com/ankitraj-1602/TaskFlow) — Multi-Tenant Project Management SaaS

A full production-style build with authentication, RBAC, real-time collaboration, caching, background jobs, and CI/CD.

**Live Demo:** [task-flow-tau-amber.vercel.app](https://task-flow-tau-amber.vercel.app) · **API:** [taskflow-90rv.onrender.com](https://taskflow-90rv.onrender.com)

- 🔐 JWT auth with refresh rotation, email verification, RBAC across 5 roles
- 📋 Kanban board with drag-and-drop, real-time notifications via Socket.IO
- ⚡ Redis caching (dashboard: 400ms → 20ms) + BullMQ background jobs
- ✅ 121 Jest tests, CI/CD via GitHub Actions, Dockerized, fully deployed
